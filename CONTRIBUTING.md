# Contributing

Thanks for helping improve the handbook!

For a new chapter: (1) give a plain-English mental model, (2) include correct Java 21 code with expected output, (3) show a meaningful diagram if it helps, (4) discuss production trade-offs and pitfalls, (5) add natural interview answers, (6) update the roadmap and MkDocs navigation.

Please keep original writing, reference official docs where possible, and do not upload confidential employer code, interview content under NDA, credentials or private user data.

Corrections through pull requests are welcome. Describe the Java/Spring version used when reporting a technical problem.
