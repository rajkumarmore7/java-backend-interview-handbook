## Detailed chapters planned

**Module 1:** Java architecture; types/operators/control flow; classes and constructors; OOP principles; Strings and immutable design; Object methods.

**Module 2:** Exception handling; Generics; Collections hierarchy; HashMap and concurrency; sorting; File I/O and NIO; Serialization; Regex.

**Module 3:** Functional interfaces; Lambdas; Streams; Collectors; Optional; Date/Time; Records; Sealed classes; Virtual threads; Java 17/21 features.

**Module 4:** Thread lifecycle; Synchronization; Java Memory Model; Locks and atomics; Executors and CompletableFuture; JVM memory; GC and profiling.

**Module 5:** IoC/DI; Beans and scopes; MVC and REST; Boot auto-configuration; Validation; Security/JWT/OAuth2; Transactions; Observability.

**Module 6:** Querying; Indexes and EXPLAIN; Deadlocks/isolation; JDBC; Hibernate/JPA; Caching; Stored procedures; SQL challenges.

**Module 7:** Service boundaries; API Gateway; Retry/Timeout/Circuit Breaker; Saga; Idempotency; Consistency; Distributed tracing.

**Module 8:** Kafka internals; Consumer groups and offsets; Delivery semantics; Duplication; Lag; Dead letter patterns.

**Module 9:** SOLID, GoF patterns, clean code and refactoring.

**Module 10:** High-level and low-level design; scalability; caching; load balancing; rate limiting; slow APIs and batch performance.

**Module 11:** Unit/integration tests; logging; Git/Maven; Docker; Kubernetes; CI/CD; Azure/AWS; SDLC/Agile.

**Module 12:** Java coding; SQL coding; debugging; real-world project storytelling; technical-lead scenarios.

## Suggested study order

Java architecture → OOP → Collections → Java 8–21 → Concurrency/JVM → Spring → SQL/JPA → Microservices → Kafka → System Design → Mock Interviews.
