# Java 21 mini-lab

Requires **JDK 21** installed and `javac` on PATH. This lab uses no third-party libraries or Maven.

From this directory, run:

```bash
javac -d out src/HashMapLab.java src/StreamLab.java
java -cp out HashMapLab
java -cp out StreamLab
```

**Expected outputs**

```text
APPROVED
Two
[2, 3]
```

Try changing the map key and input list, then explain the observed results.
